## Colors

April has two color layers:

1. **Primitive colors** (`gray/gray-900`, `primary/primary-800`, etc.) — raw palette from Figma Mode 1. Source: `src/data/mode-1-primitive-colors.json`. CSS vars: `--gray-gray-900`, `--primary-primary-800`, etc.
2. **Semantic colors** — component-facing tokens that alias primitives. Source: `src/data/semantic-colors.json`. CSS vars: `--color-background-*`, `--color-foreground-*`, `--color-border-*`.

### Enforcement

- **Always use semantic tokens** when applying background, foreground, border, text, or icon colors in component CSS, helpers, or Storybook markup.
- **Never** use primitive hex values or `--{family}-{shade}` vars directly in components — e.g. use `--color-foreground-text-text-default`, not `--gray-gray-900`.
- **Missing token:** If no semantic token exists for a component property, **ask before implementing** — do not guess or substitute a primitive.
- Primitives are for the token gallery, alias resolution, and design tooling only.
- Regenerate CSS after updating either JSON file: `npm run generate:tokens`.

- **Calendar Popover — composition.** Every selectable item is a Base Date Cell — `data-cell="date"` for days, `data-cell="year"` for years and months. The popover never renders its own day/month/year buttons. Four variants share one shell, controlled by `state`: `single-date` · `range` · `month` · `year`.

- **Calendar Popover — range fills.** A selected range always reads as: `range-start` (dark, `primary-800`) → N × `range` (light, `primary-200`) → `range-end` (dark, `primary-800`). Never swap endpoints to light or middles to dark. Single-day selection (`active`) uses the inverted ring pattern: date cells get _primary-200 fill + primary-800 ring_; year/month cells get _primary-800 fill + primary-200 ring_.

- **Calendar Popover — header & footer.** Title (left) is a `link` button that drills up the picker hierarchy (date → month → year). The `‹ Today ›` cluster (right) is prev/next nav around a Today shortcut. The Year picker title is static. Only the `range` variant carries a footer: `Reset All` (link button) + `Done` (`button type=primary size=md`). Other variants commit on click.
